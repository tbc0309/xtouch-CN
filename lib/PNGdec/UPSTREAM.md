# PNGdec

Source: https://github.com/bitbank2/PNGdec
Version: 1.1.7, commit `b862a89409962366fd704ed0445b983a710f034c`.

Vendored `src/`, `LICENSE` and Arduino library metadata. Source files are unchanged.
The project sets `PNG_MAX_BUFFERED_PIXELS=4128` and uses bounded, row-based
RGB565 decoding for print thumbnails. The license and bundled zlib notices
remain with the source.

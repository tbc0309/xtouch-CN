# ESP32-S3-Touch-LCD-2.8 V2

| 项目 | 接线 / 配置 |
|---|---|
| LCD | ST7789，MOSI 45、SCLK 40、CS 42、DC 41、RST 39，80 MHz SPI |
| 背光 | GPIO5，20 kHz / 10 bit PWM |
| 触摸 | **CST3530 / V2**，Wire1：SDA 1、SCL 3、RST 2、INT 4，地址 0x58 |
| SDMMC | 1 线：CLK 14、CMD 17、D0 16；D3 21 拉高 |
| 电池供电保持 | GPIO7 拉高，休眠时保持电池供电 |
| 按键 | GPIO6 电源键在程序运行后短按切换联网休眠／唤醒；RESET 为硬件复位 |
| 存储 | 16 MB Flash、8 MB 八线 PSRAM；256 KB LVGL 内存池放入 PSRAM |
| 音频 | PCM5101：BCLK48、LRCK38、DOUT47，无软件功放使能 |

构建：激活 ESP-IDF 6.1 后，在仓库根目录运行 `python boards/build.py s3`。

电容屏不需要 CYD 的触摸校准。摄像头支持局域网 JPEG 流，RTSPS 的机型与资源限制见[摄像头说明](../README.md#摄像头)。IMU、独立 RTC 和电池电量显示未加入此应用。

触摸音和警告音默认关闭。联网待机保留 MQTT，使用80–160 MHz自动调频，保持网页管理；未启用自动轻睡眠；可选深睡支持触摸唤醒和复位键启动，并保持 GPIO7 电源锁存；启用后的默认等待时间为 60 分钟。电源、充电指示灯为硬件接线，不能软件关闭。


显示按微雪 V2 示例配置 ST7789 面板驱动、时序与 Gamma，使用原生小端 RGB565。界面在 PSRAM 中合成并按面板原生扫描方向连续 DMA 传输，绘制与发送分别使用独立缓冲；小区域更新保留局部传输。LVGL 使用 48 行内部绘制缓冲。刷新与触摸周期分别为 16 ms、8 ms，实际速度取决于页面绘制负载。界面处理期间使用 CPU 最高频率锁，完成后释放，保留空闲降频。

## 屏幕与网页操作

### 控制屏

| 页面或控件 | 操作 |
|---|---|
| 首页设备卡片 | 点按切换；三台及以上时打开设备选择页，长按始终打开设备选择页 |
| 首页 AMS 色块 | 多单元时点按循环浏览 |
| 打印进度条 | 准备阶段为黄色，开始打印后为绿色 |
| 灯光 | 点按开关，显示打印机反馈的状态 |
| 温度／风扇 | 打开数字键盘，左侧选参数，绿色键确认；红色键删除，输入为空时返回 |
| 喷头“更多” | 查看当前机型支持的喷头、热端仓和仓温操作 |
| 耗材页 | 选择来源后进料、退料或重读；长按 AMS 名称查看详情 |
| 运动页 | 选择步距后移动；归位和挤出等操作需确认 |
| 设置版本号 | 连点三次检查 OTA；连点八次打开重置确认 |

设置页与设备选择页需滑动停稳后再操作，避免翻页时误改或误选。三种主板共用全屏设备选择页，支持图片／列表切换并记住选择（CYD、S3 每排两台，P4 每排三台），绿色表示当前设备；内容超过一页时，右侧显示滚动进度。

超出范围的数值不会发送。切换数字键盘参数会清除未确认的输入。打印或设备忙碌时，相关手动控制不可用。

S3 电源键、P4 BOOT 键在运行后短按可切换联网休眠与唤醒。RESET 为硬件复位；P4 POWER 为硬件电源开关。P4 仍可按住 BOOT、点按 RESET 进入下载模式。

设备来源图标：局域网为蓝色、Token 为橙色、手机号账号为绿色、邮箱账号为灰色；颜色表示连接来源，不表示在线状态。

### 网页管理

屏幕语言和后台语言分别保存在设备配置中，均默认英文，互不影响。已保存屏幕语言时，启动画面也使用该语言；未配置时默认英文。后台登录页和管理页共用后台语言；登录前选择的语言在登录成功后保存。首次 Wi-Fi 配网所选语言同时初始化两者。

已有设备和账号的可编辑字段双击解锁，键盘聚焦后也可按 F2 / Enter；未改动时失焦回锁，待验证的修改在保存成功前保持可编辑。设备名称和账号备注接受最多 63 个 ASCII 英文字母、数字、符号及空格。

Token 验证成功后，备注可解锁修改并自动保存；修改 Token 后需重新点击“验证并获取设备”。账号登录的手机号／邮箱和区域只读。清除登录保留账号与关联设备，重新登录前显示失效。

最多保存 50 个拓竹账号、100 台打印机，一次连接一台；实际可保存数量受主板可用内存及凭据长度影响。

| 操作 | 保存与生效 | 是否重启 |
|---|---|---|
| 亮度、语言、休眠、声音、深睡及开机选项 | 有效修改自动保存并应用 | 否 |
| 设备名称、账号备注、关联设备 | 自动保存；连接资料变化时重连打印机 | 否 |
| 新账号或修改 Token | 验证成功后保存，无关联设备也可保存 | 否 |
| Wi-Fi | 自动保存并重连，设备地址可能变化 | 否 |
| 导入备份 | 确认并校验后保存、应用 | 否 |
| 管理密码 | 提交后生效，重新登录后台 | 否 |
| 固件升级、重置设备 | 确认后执行 | 是 |
| 屏幕翻转 | 确认后保存并应用 | 是 |

无效输入、未完成的新账号和验证失败的 Token 不会覆盖已保存配置。需要重启时，页面显示“保存并重启”按钮及红框提示。ESP32-2432S028R 访问配置时可能短暂重连打印机。

### 显示、休眠与声音

默认亮度 200、音量 20%、休眠时间 15 分钟。自动深睡、触摸音和警告音默认关闭。三板均支持提示音，可在屏幕或后台调节音量。状态 RGB 灯默认开启。

普通休眠关闭屏幕并保持联网，后台仍可访问，支持打印唤醒。开启自动深睡后，默认在联网待机 60 分钟后、打印机空闲且无任务时进入深睡。深睡会断网，触摸屏幕或按复位键重新启动，配置保留。

控制屏及网页支持八种语言。内置字库覆盖界面文字，外部名称中的部分字符可能显示为空框。

<a id="notifications"></a>

AMS 色块中的原色区域表示剩余耗材：耗材页从右向左填充，首页从下向上填充，消耗部分显示为淡色；未知余量保持纯色。耗材页 AMS 名称固定，读数按温度、湿度顺序显示。可用空间不足以完整显示温度时隐藏读数，否则过长的读数会滚动。

## 提示与故障处理

| 类型 | 显示与操作 |
|---|---|
| 信息 | 蓝色提示条，通常 2–3 秒后消失，可点按关闭 |
| 警告 | 黄色标识；权限提示短暂显示，重要警告需确认 |
| 错误 | 红色标识，保留原始错误码，需确认关闭 |
| 操作确认 | 显示设备、操作及参数，选择确认或取消 |

温度、运动、进退料、烘干、暂停、取消、重启和重置等操作会要求确认。确认超过 30 秒、切换设备或出现新故障时失效；不会自动重发超时的机械控制命令。

### HMS 与打印错误

HMS 是打印机的健康报告，打印错误是当前任务或设备故障；两者可在同一弹窗显示。已确认且持续存在的相同故障不反复提醒，新增故障会再次提示。代码清除后界面随之更新。

- **关闭**：只关闭本地提示，不清除打印机错误，也不恢复打印。
- **重试**：仅对支持该动作的当前打印错误请求恢复。
- **完成**：仅对支持该动作的当前打印错误报告处理完成。

授权错误 `84033543` 和 HMS `0500-0500-0001-0007` 显示“部分控制功能需局域网模式及开发者模式。”，同一设备会话中不重复自动提醒。再次主动发起被拒绝的操作仍会显示失败。处理方法见[控制权限](PRINTERS.md#authorization)。

默认固件显示错误码；完整含义可在[在线查询页](https://tbc0309.github.io/xTouch-CN/errors.html)或[故障码文档](ERROR-CODES.md)中搜索。

### 网页提示

自动保存结果显示在右上角；登录与配网提示显示在对应卡片下方。后台会话失效时重新登录设备管理；拓竹 Token 失效时更新对应账号。临时网络失败不会删除已保存账号。


Wi-Fi 配网热点开启时，只有通过设备热点访问才能免登录配网；通过路由器访问仍需管理密码。登录、配置及备份响应不缓存，退出登录后会话失效。

## 拓竹账号登录方式

S3、P4 网页后台的拓竹账号提供 **Access Token** 和 **账号登录** 两种正常入口。中国区使用手机号，国际区使用邮箱；需要验证码时，按照页面提示完成验证。CYD 仅提供 Access Token。实际入口由固件编译时选择的认证模块决定。

账号登录成功后仍使用 Token 会话。保存的密码可用于会话失效后的重新登录尝试，但验证码等交互验证仍需用户完成，不能保证自动免验证登录。“加密并绑定”默认不勾选；绑定密钥被重置后，原密文不能恢复。导出的配置备份请妥善保管。

# 固件体积与内存管理

适用于 xTouch-CN 1.0.0，4MB Flash、无 PSRAM。

## 分区与构建

OTA 应用槽为 1,966,080 字节；内部配置使用独立的 128KiB SPIFFS。构建脚本检查应用上限，输出应用大小与剩余空间；正常发布构建不含串口模拟或自检入口。

发布体积见本文末尾的构建数据。静态 RAM 为 92,576 字节，运行时可用内存随连接方式和页面变化。

## 空间与内存措施

- 固件只保存故障码及动作规则；3,267 条 HMS 和 1,117 条打印错误说明位于文档与查询网站，不编入应用。
- 八种语言使用精简字形集，仅包含界面所需字符。
- 管理网页压缩为 gzip，不在固件中保留重复语言页面。
- MQTT 使用按需分配的 1KiB 分块缓冲，上限 61,439 字节，过滤解析后回收；超大消息整包丢弃，后续正常消息可恢复。
- HMS 最多保留 50 条，去重排序后与打印错误合并显示；使用小型格式缓冲，关闭弹窗后释放列表文本。
- 详情页退出后释放对象；设备切换清理旧状态和待确认命令。

## 验证范围

八语各 83 个基础翻译键与现用字形覆盖检查通过。实机模拟测试覆盖页面反复创建／销毁、超限 MQTT 帧恢复、故障重复更新、SD 配置迁移和固件升级。测试不代表无限运行或全部新机型机械动作均已验证，边界见 [新机型与 AMS](NEW-MODELS-AMS.md) 和 [安全检查](SECURITY-REVIEW.md)。

## 1.0.0 发布构建

应用镜像 1,747,152 字节，OTA 余量 218,928 字节（213.8 KiB）。静态 RAM 为 92,576 字节。

## 配置与备份

设置保存在设备内部，日常使用无需 SD 卡。插入 SD 卡后，可同步备份以下文件：

| 文件 | 内容 |
|---|---|
| 根目录 `xtouch.json` | Wi-Fi、打印机、拓竹账号和开机默认设备 |
| `xtouch/settings.json` | 语言、亮度、休眠、声音及 OTA 设置 |
| `xtouch/touch.json` | 本机触摸校准 |
| `xtouch/hardware.json` | 屏幕方向 |

触摸校准仅适用于对应设备；S3/P4 使用出厂触摸坐标，无需 CYD 校准。后台维护页也可下载和导入配置备份。

### 时间配置

`xtouch/settings.json` 可设置 `timezone`（POSIX 时区规则）、`timezoneName`（时区名称）、`ntpServer` 和 `browserTimezoneSync`：

```json
{
  "timezone": "CST-8",
  "timezoneName": "Asia/Shanghai",
  "ntpServer": "ntp.aliyun.com",
  "browserTimezoneSync": true
}
```

浏览器时区同步默认开启，NTP 默认使用 `ntp.aliyun.com`。时区为空且浏览器同步开启时，首次登录后台自动填入浏览器时区并保存；之后以配置为准，不会被其他浏览器覆盖。`timezoneName` 仅作说明，实际时间按 `timezone` 计算。例如纽约可使用 `EST5EDT,M3.2.0,M11.1.0`，包含夏令时规则。未配置时暂用北京时间；NTP 同步完成后才显示时间。修改时区或 NTP 服务器无需重启。

### SD 同步与恢复

手动编辑 TF 卡中的 `xtouch.json` 时，非空 `token` 优先于旧密文。使用新明文 Token 时，删除旧的 `tokenEnc`，并将 `tokenEncrypted` 设为 `false`。安全弹出卡后插回设备或重启，让配置同步并加载。

没有有效内部配置时，设备会导入 SD 上的有效配置。内部与 SD 均有配置时，根据修改时间、版本和同步状态选择；无法确定先后时优先保留尚未备份的内部修改。手动编辑 `xtouch.json` 后，可保留或移除固件管理的 `_storage` 字段。

运行中导入新的 SD 配置会重启；仅回写备份不会重启。无效 JSON 不会覆盖有效内部配置。没有 SD 卡或写卡失败时，内部设置保留，之后再同步。

| 附加文件 | 用途 |
|---|---|
| `*.previous` | 上一次有效保存，主文件损坏时用于恢复 |
| `*.conflict` / `*.invalid` | 冲突或无效输入的备份，不自动加载 |
| `*.tmp` / `*.part` | 保存或下载中的临时文件 |
| 根目录 `firmware.bin` | SD 更新用的应用固件 |
| `xtouch/ota.json` | 更新过程中的临时清单 |

确认当前配置正确后可清理不需要的备份。不要在保存或升级期间断电或拔卡。更新步骤见[安装与升级](INSTALLATION.md#install)。

### 擦除与重置

普通应用升级保留内部配置。网页 USB 安装取消勾选 **Erase device** 时保留用户数据；勾选后清空内部 Flash，但不会删除 SD 备份。需要全新配置时先移除 SD 卡，否则开机可能自动恢复旧配置。

设备重置清除内部配置和管理密码，保留 SD 文件。有卡时可重新导入；无卡时重新配网。重置会更换设备密钥；旧备份中的加密 Token 无法解密时，账号保留但登录失效，需要重新填写 Token。

内部配置无法挂载时，先保留可用备份，再通过网页安装恢复。三板分区不同，不要套用其他主板的擦除地址。

## 安全说明

- 管理后台使用密码和单浏览器会话；新登录替换旧会话。初始密码 `12345678` 须在首次登录后修改。
- 后台使用局域网 HTTP，请只在可信网络使用，不要直接暴露到公网。
- Token 和局域网访问码的“加密并绑定”默认不勾选，以明文保存；勾选后使用设备绑定加密。双击编辑 Token 或访问码后，输入框为空时加密选项与验证按钮保持置灰；输入内容后才能操作，验证成功才保存。原有勾选状态保留。密钥不随备份导出，恢复到另一块板或重置后，加密凭据需重新填写。
- Wi-Fi 密码为明文。配置及 SD 备份应妥善保管，不要公开分享或上传。管理密码独立保存为带随机盐的 PBKDF2 哈希，不绑定凭据密钥，也不包含在配置备份中；导入普通配置不会替换管理密码或注销当前会话。修改管理密码会注销当前会话。
- 设备未启用硬件 Flash 加密，内部存储不能防止物理读取。
- 云 API、云 MQTT 和在线更新校验证书；本地打印机连接兼容自签名证书。固件摘要校验用于检测文件损坏，不等同于发布者签名验证。
- 保存失败或可用内存不足时，原配置保留。最多保存 50 个拓竹账号、100 台打印机，一次连接一台，实际容量受内存及凭据长度影响。

控制权限与机型支持见[兼容说明](PRINTERS.md#authorization)。

设备连接方式由添加来源确定，只读显示。修改局域网型号、序列号、地址或访问码后，需点击 **验证并保存设备**；未修改的已保存访问码可继续用于验证。未保存的配置以红框标记，修改后的字段保持可编辑，验证失败不会锁定；保存成功后恢复已保存样式。刷新页面会丢弃未保存修改。拓竹账号的 Token 和区域修改同样需重新验证，备注仍自动保存。

### 配置文件样板

[完整配置样板](../examples/xtouch.json)使用虚构的 Wi-Fi 和打印机信息，导入前须替换。它与后台导出格式一致：根对象保存 Wi-Fi、打印机和拓竹账号，`settings` 保存设置。TF 卡单独保存设置时，将该对象的内容放入 `xtouch/settings.json`，不要再套一层 `settings`。

- `activePrinter` 为从 0 开始的打印机索引；无设备时填 0。最多 100 台打印机、50 个拓竹账号；云设备的 `accountId` 必须引用已存在的账号 `id`。
- JSON 使用 UTF-8，布尔值为 `true`／`false`，数值不加引号；设置可省略，省略项使用默认值。`deepSleepAfter: 0` 表示关闭自动深睡。
- 账号由后台验证后生成，不要把页面中的健康状态、掩码或验证码写入配置。密文由设备生成，不要自行构造；明文与对应密文字段只保留一种。
- `_storage` 为同步元数据，由固件维护，不属于手动配置样板。配置写入使用临时文件、内容校验和上次有效版本；内容未改变时不重复写入。

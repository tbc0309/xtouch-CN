# 控制屏与后台交互

## 控制屏

| 区域 | 点按 | 长按 / 滑动 | 执行规则 |
| --- | --- | --- | --- |
| 首页设备卡片 | 最多四台时顺序切换；更多时打开列表 | 长按始终打开列表 | 列表点选；拖动不选中设备 |
| 首页 AMS 色块 | 多单元时循环浏览 | 无长按控制 | 仅浏览；返回首页恢复首个单元 |
| 灯 | 开关灯 | 无长按控制 | 可立即撤销的操作，不追加弹窗 |
| 温度 / 风扇 | 打开原版数字键盘 | 无长按控制 | 左侧切换参数，右侧输入；切换参数不会发送命令 |
| 数字键盘红键 | 删除；输入为空时取消返回 | 无长按控制 | 取消不会写入目标值 |
| 数字键盘绿键 | 确认当前参数 | 无长按控制 | 温度再确认目标后发送；风扇直接提交合法百分比；烘干参数先保留草稿 |
| 喷头数字页“更多” | 打开喷头动作与热端仓入口 | 无长按控制 | 换喷头、挤出、回抽及热端仓动作均先确认 |
| 耗材页 AMS 名称 | 选择单元 | 长按查看详情；过多时左右滑动 | 不直接换料 |
| 耗材槽位 | 选择或取消选择 | 无长按控制 | 蓝框是界面选择，实际装载状态单独显示 |
| 进料 / 退料 / 重读 | 对所选来源发起请求 | 无长按控制 | 确认来源后执行；外置不提供 RFID 重读 |
| 重读右侧“烘干” | 打开当前 AMS 的烘干详情 | 无长按控制 | 仅支持 Pro / HT 且处于 AMS 浏览上下文时拆分卡片；其它情况保留完整重读卡片 |
| 烘干温度 / 小时 | 进入同一数字页，左侧切换 | 无长按控制 | 修改参数本身不启动；“开始烘干”确认后才执行 |
| 运动页方向键 | 按当前 1 / 10mm 步进移动 | 不定义隐藏的长按动作 | 只在在线、空闲且状态允许时操作 |
| 归位 | 显示一次移动确认 | 无长按控制 | 打印、暂停、准备、忙碌及非 FDM 模式禁用手动运动 |

温度、风扇及烘干参数使用统一数字键盘。按左侧参数切换时清除尚未确认的输入；绿键只确认当前参数。超范围输入不会发送，输入框提示有效范围。

确认绑定打开时的设备，超过 30 秒失效；切换设备时关闭旧确认。执行前重新检查在线状态、范围、能力及相关忙碌状态。控制请求尚未结束时不并发发送另一条相关请求。

请求发送、设备接受使用短提示；失败和超时只提供一个确认按钮。提示不覆盖正在等待用户决定的操作确认。“接受请求”不代表设备已经完成机械动作或加热过程。

HMS 与当前打印错误共用一个可滚动弹窗；新增故障取消旧操作确认，重复报告不再次弹出。代码清除、先后到达与按钮适用范围见[提示与故障弹窗](PROMPTS.md)。

## 网页后台

- 已有设备的可编辑输入框使用虚线边框和编辑标记，双击解锁；键盘聚焦后按 F2 / Enter 也可编辑，失焦重新锁定。
- 新增局域网设备直接填写。云设备只可修改自定义名称；型号、序列号与关联账号为展示信息。
- 自定义设备名、账号备注仅接受 ASCII 英文字母、数字、英文符号和空格，最长 63 个字符。浏览器和保存接口分别检查；不会修改密码、Token 或 Wi-Fi 名称的字符规则。
- 不支持字符的已有名称不会导致整份配置失效；控制屏使用安全的默认名称。再次保存时应改为允许的名称。
- “保存并重启”统一位于右上角；未保存变更使用待保存状态提示。选择、展开、双击解锁和浏览不会自行保存。

## 数据与能力

LAN 与 Cloud 只有连接认证、地址及状态超时不同，共用同一个 MQTT 解析及能力判断流程。运行时上报型号优先于配置里的型号。

设备上报的 `support_chamber_temp_display`、`support_chamber_temp_edit`、调节范围、辅助风扇和仓室风扇支持字段优先参与判断。旧协议没有能力字段时使用已核对的型号规则；未知数据不冒充有效的零值。

P1 系列的网络仓温占位值不覆盖外接传感器。A1 系列没有有效仓温能力时不显示仓温卡片。缺失的增量字段保留上次状态，显式无效温度显示 `--`。新风道协议不套用旧风扇控制命令。

协议依据：[BambuStudio DevConfig](https://github.com/bambulab/BambuStudio/blob/79df7ae309be398ed30c9f397c13c9911c2edc57/src/slic3r/GUI/DeviceCore/DevConfig.cpp)、[DevFan](https://github.com/bambulab/BambuStudio/blob/79df7ae309be398ed30c9f397c13c9911c2edc57/src/slic3r/GUI/DeviceCore/DevFan.cpp)。

English summary: tap selects or opens an explicit control; long press opens lists/details, never a hidden actuator command. Numeric controls reuse the original keypad. Existing web fields require double-click or F2; custom names use printable ASCII. LAN and Cloud share telemetry parsing and capability checks.

## 语言与显示

控制屏、配网和管理页支持简体中文、繁体中文、英语、法语、德语、俄语、日语、韩语。后台默认跟随浏览器语言，不支持的语言使用英语。

耗材页按设备能力显示烘干入口；外置耗材只在设备有有效上报时显示。缺字显示空心方框。云端控制授权限制见 [云端控制](CLOUD-CONTROL.md)。

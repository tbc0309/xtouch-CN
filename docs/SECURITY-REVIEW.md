# 安全措施与验证范围

适用于 xTouch-CN 1.0.0，不构成第三方安全认证。

## 安全措施

- 管理后台使用密码登录、单浏览器会话、CSRF 与来源检查；配置接口隐藏已保存凭据。
- 管理密码保存为带随机盐的 PBKDF2-SHA256 校验值。可选保存的云密码使用 AES-256-GCM，密钥绑定设备并存放于 NVS。
- 云 API、MQTT 与 OTA 校验证书。固件更新检查镜像格式、大小；在线更新还校验清单摘要与长度。
- HTTP 请求行、请求头、正文和 multipart boundary 均有长度限制；非法长度与不支持的传输格式被拒绝。
- MQTT 帧最大 61,439 字节，解析失败或容量不足时整帧丢弃。设备 ID、槽位、数值范围、能力和忙碌状态分别检查。
- 控制确认绑定当前设备；切换、超时或状态变化使旧确认失效。请求回复核对设备、序号和命令。
- 配置原子保存，原版配置迁移前保留备份，删除标记参与 SD 同步。

## 依赖与修复依据

- 使用 ArduinoJson 6.21.6，参见 [数字解析安全公告](https://arduinojson.org/news/2026/03/02/security-update/)。
- 同步 HTTP 服务回移有界 multipart 修复，参见 [Arduino-ESP32 公告](https://github.com/espressif/arduino-esp32/security/advisories/GHSA-8cmm-3887-r32j)。源码与授权位于 `lib/XTouchWebServer`。

## 验证范围

覆盖认证拒绝、会话替换、CSRF、Origin、凭据脱敏、异常 HTTP／JSON 输入、固件输入校验、配置恢复与 OTA；模拟验证覆盖各内置机型协议代码、AMS 组合、参数边界、异常遥测和故障状态更新。实体控制屏反复切页及请求测试未观察到持续内存下降。

原版与 CN 0.9.215 的 SD 升级已通过 CYD 实机验证。新机型机械动作、双喷头加热和 AMS 烘干仍需对应硬件验证，不能由模拟回复推断实际执行成功。

## 使用边界

后台为局域网 HTTP，Cookie 与 CSRF 不提供链路加密；本地打印机采用兼容自签名证书的 TLS 连接。设备绑定密钥不能替代 Flash 加密或抵抗物理读取。配置备份含访问凭据，应妥善保管。镜像格式及摘要校验不等同于发布者签名验证。

普通发布构建不包含模拟串口入口；私有配置与测试日志不纳入项目。长期耐久、100 台完整配置及全部新机型实机控制不属于已验证范围。

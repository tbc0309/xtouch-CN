## 状态与耗材控制

可用功能取决于打印机型号、固件、已连接外设和连接权限。局域网与拓竹账号连接均可显示打印机上报的状态。

| 功能 | 说明 |
|---|---|
| 打印状态 | 进度、剩余时间、层数及暂停、恢复、取消 |
| 温度 | 喷嘴、热床的实际与目标温度；有效仓温 |
| 风扇与速度 | 支持的风扇百分比、打印速度档位 |
| AMS | 材料、颜色、有效余量、湿度及箱内温度 |
| 耗材控制 | 进料、退料、RFID 重读；支持的 AMS 烘干 |
| 运动 | 空闲时归位、按步距移动及挤出／回抽 |

无效或未上报的读数不会显示为零；湿度等级与湿度百分比属于不同读数。耗材余量仅显示打印机提供的数据。

### 耗材操作

1. 进入耗材页，选择 AMS 槽位或外置耗材。蓝框表示所选来源，绿框表示实际装入的来源；点选本身不会换料。
2. 点击进料、退料或重读，核对确认框中的来源后执行。再次点击同一槽位可取消选择。
3. 退料只针对实际装入的来源；RFID 重读仅适用于 AMS，不适用于外置或无 RFID 的耗材。

进料可能触发退料、加热和打印头移动。没有有效耗材温度时，先设置喷嘴温度。打印、暂停、准备、AMS 忙碌或读取标签期间，相关手动操作不可用。

多 AMS 可左右滑动选择，外置入口固定在右侧。长按 AMS 名称可查看详情。

## 喷头、AMS 与烘干

### 喷头与仓温

点击温度卡片打开数字键盘，左侧选择参数，输入数值后按绿色确认键。喷嘴温度支持 0–300°C 的整数，0 表示关闭加热。

“更多”菜单按机型提供 T0/T1 切换、指定喷头挤出／回抽 10 mm、热端仓和主动仓温入口。挤出／回抽要求对应喷头至少 170°C；运动操作仅在空闲且状态允许时启用。

H2C 热端仓可显示位置、直径和类型，并提供重读、确认、归位及升起 A/B 操作。自动完整热端交换未提供。

主动仓温仅适用于具备加热能力且目标读数有效的机型：X1E 上限 60°C，其余已支持的加热机型上限 65°C。P1S 不支持主动仓温加热，其无效占位读数不会显示。

### AMS 与烘干

支持烘干的 AMS 在耗材页显示“烘干”入口。修改温度和时长后，确认“开始烘干”才会启动。

| 外设 | 烘干温度 | 时长 |
|---|---|---|
| AMS 2 Pro | 45–65°C | 1–24 小时 |
| AMS HT | 45–85°C | 1–24 小时 |
| AMS / AMS Lite | 无烘干控制 | — |

打印、准备、暂停时不能启动烘干。检查、烘干和冷却期间可请求停止。旋转料盘、自定义冷却温度、自动烘干和共享供料绑定重分配未提供。

双喷头和双路外置耗材按打印机报告的绑定关系显示；来源不明确时禁用相关控制。新式风道、新热床及其他未适配能力没有独立控制入口。H2C 热端仓、双喷头、双路外置和 Pro/HT 烘干的完整实机兼容性尚未确认。

## 局域网与云端授权

**部分控制功能需局域网模式及开发者模式。**

拓竹账号 Access Token 用于连接账号、获取设备和订阅状态，不保证打印机接受所有控制命令。当前版本不支持官方云端命令签名通道。

出现 `84033543` 或授权 HMS `0500-0500-0001-0007` 时，请使用对应打印机的局域网设备配置，并核对打印机的局域网模式与开发者模式。更新 Token 不能解除命令授权限制。

灯光、温度、风扇、运动、暂停／恢复／取消及 AMS 操作的权限可能随机型和固件变化。以打印机反馈及实际状态为准；“请求已接受”不表示机械动作已完成。

## 型号与显示

首页根据打印机报告的型号显示图片；收到有效型号前或型号未知时显示 xTouch 标志。图片覆盖 X1 / X1 Carbon / X1E、P1P / P1S、A1 / A1 mini、P2S、X2D、A2L、H2C、H2D、H2D Pro 和 H2S。图片识别不代表全部控制功能兼容。

任务缩略图未就绪时显示机型图；ESP32-2432S028R 始终使用机型图。摄像头与缩略图条件见[摄像头说明](../boards/CAMERA.md)。

首页设备卡片点按可切换设备：两台以内依次切换，三台及以上打开设备选择页；长按始终打开设备选择页。长名称滚动显示，切换后清除原设备的耗材选择和故障提示。

耗材余量不超过 10% 显示红色，11–20% 显示黄色，其余正常显示。余量未知时不显示百分比。

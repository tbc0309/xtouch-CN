# 提示与故障弹窗

界面显示状态、错误码和操作确认。控制屏及后台均按当前语言显示，未知语言回退英文。

## 类型标识与打扰级别

| 类型 | 标识 | 使用场景 |
| --- | --- | --- |
| 信息 | 蓝色 i 图标＋“提示” | 已知普通信息，单条 2 秒、多条 3 秒提示条 |
| 警告 | 黄色 ! 图标＋“警告” | 权限提示 4 秒、忙碌或状态改变 1.8 秒提示条；设备上报的重要警告需手动确认 |
| 错误 | 红色 ! 图标＋“错误” | 故障、未知错误、请求超时，保留完整代码，手动确认 |
| 操作确认 | 蓝色 ? 图标＋“确认操作” | 用户主动发起且需确认的操作，保留取消与确认 |

标题随八种界面语言切换；图标以界面矢量绘制，不依赖 emoji。提示条不会遮罩全屏，不抢占正在处理的确认或故障窗口。相同内容与类型的重复报告不会延长计时；新故障取消旧提示和旧计时器。请求发送和接受不另弹成功提示，摄像头与连接状态继续在原页面内显示。

## 公用提示

| 提示 | 出现条件 | 行为与复用位置 |
| --- | --- | --- |
| 错误码 `84033543`；部分功能仅支持局域网模式，且开启开发者。 | 打印机拒绝命令验证 | 适用于温度、运动和耗材等控制。需要改用 LAN 设备连接，不能保证只改打印机开关就能使 Cloud 命令可用 |
| 控制命令被拒绝；错误码 `n` | 收到明确的命令拒绝回复 | 有代码时保留原码；无代码时只显示控制请求被拒绝，不伪造错误码 |
| 控制请求发送失败，请检查连接 | 本地 MQTT 发布失败，未成功发出请求 | 不显示为打印失败，不将本地失败编号冒充打印机错误码 |
| 设备忙或状态已变更 | 打开确认后切换设备、超时、能力或忙碌状态改变 | 关闭过时的操作确认，不发送控制命令 |
| 请求已发送，等待设备响应 | 耗材、喷头、烘干控制已发布 | 不额外弹窗；由待应答状态与实时参数显示进度，不能视为成功 |
| 设备已接受请求 | 对应请求收到成功回复 | 不额外弹窗；不能视为加热、进退料或机械动作已完成 |
| 等待超时，请检查设备状态 | 对应请求未及时收到回复 | 常驻，点确认关闭；不擅自重发动作 |
| 正在切换到设备名称 | 切换设备 | 在连接等待位置短暂显示；不是独立弹窗 |

命令回复仅匹配本设备发出的请求序号、命令和设备，不将同主题里其它客户端的回复作为自己的结果。`print` 与 `system` 控制统一处理错误；AMS、喷头和烘干仍匹配各自待应答请求。

## 按钮数量与颜色

按钮按实际动作显示，不固定放满三个。未知错误或仅 HMS 不提供恢复命令，只显示灰色“关闭”。已知打印错误按机型规则增加蓝色“重试”或绿色“完成”；规则同时支持两项时保留两项与“关闭”。“重试”发送恢复请求，“完成”发送已处理请求，“关闭”只收起本地窗口，三者不能互相替代。当前规则表有 7 种代码按机型支持双动作，并非所有错误都显示三个按钮。

普通操作确认使用灰色取消、蓝色确认；取消打印、恢复出厂的确认按钮使用红色。完成处理使用绿色。按钮同时保留图标与文字，不只依赖颜色；按下颜色统一加深。每次打开重设角色，防止从破坏性操作继承红色。失败结果的单按钮也改为灰色“关闭”，避免误以为点“确定”会修复故障。

## 操作确认

| 操作 | 必要信息 | 确认后 |
| --- | --- | --- |
| 暂停、取消打印 | 即将执行的操作 | 只执行对应操作；取消不与暂停共用文案 |
| 归位 | 打印头将移动 | 再检查设备与运动状态 |
| 设温、运动与喷嘴仓操作 | 参数、目标喷头或槽位 | 复用数字键盘；确认当前参数，不隐式提交其它参数 |
| 进料、退料 | 当前耗材槽位；可能加热、运动 | 重新验证选中耗材和设备；不能将两个动作的确认合并 |
| RFID 重读 | 耗材槽位、需要 RFID 耗材 | 只请求重读，不自动改写耗材资料 |
| 开始／停止烘干 | AMS、温度和时间或停止动作 | 只控制选中的 AMS |
| 重启、恢复出厂 | 明确的动作名称 | 普通重启不等同于清空配置 |
| 翻转屏幕 | 重启后应用 | 确认后保存重启 |

操作确认有取消与确认；失败弹窗只提供确认；短暂信息使用可点击关闭的非模态提示条。确认绑定打开时的设备，30 秒后失效。新故障出现时取消旧操作确认，防止关闭故障提示后误执行过时动作。

## HMS、打印错误码与命令错误码

| 来源 | 含义 | 例子与显示方式 |
| --- | --- | --- |
| MQTT `print.hms` | Health Management System 健康监测报告，包含警告及故障；不保证阻止打印 | `attr` 与 `code` 两个原始 32 位字段合成 `HMS 0500-0500-0001-0007` |
| MQTT `print.print_error` | 当前打印／设备错误，可能附带厂商定义的重试、完成操作 | `0x07018004` |
| 控制回复 `err_code` | 某次命令的结果；不等于持续存在的 HMS 或当前打印故障 | `84033543`；使用普通结果提示，不自动添加到设备故障列表 |

三者没有“先打印错误、然后才能出现 HMS”的前置关系。它们可单独存在、同帧到达或先后到达，也不一定一一对应。HMS 不能一律理解为严重错误，确认弹窗也不表示故障已经修复。

### 同一故障弹窗

以下为模拟上报后的实机显示示例，不代表截图中的打印机正在发生这些故障。

![打印错误与 HMS 合并显示](images/prompts/combined-faults.png)

- 同一帧先更新两类状态，再刷新一次弹窗；打印错误在前，当前 HMS 按代码排序列在后面。
- 先后到达时更新同一个弹窗，不互相覆盖，也不创建第二个故障弹窗。
- 列表过长时纵向滚动，列表高度随按钮数量调整，底部按钮固定可见。最多保留按代码排序的前 50 条 HMS，超过时显示 `...`，不为异常大报文无限分配内存。列表逐行构造，只用 32 字节临时格式缓冲；关闭后释放列表文字。
- 相同代码去重，HMS 顺序改变不算新故障。确认后持续存在的相同报告不再次弹出；新增代码或不同的打印错误才再次提醒。普通故障被打印机明确清除后再次出现，按新的故障提醒。
- 缺失的增量字段保留上次状态；`print_error: 0` 清除打印错误，`hms: []` 清除 HMS。格式错误的 HMS 数组不当成清空。全部清除时自动关闭故障弹窗。
- HMS 与打印错误保存为不同类型，不能靠数值大小判断；前半部分为零的 HMS 仍按 HMS 显示。
- 重试／完成按钮只根据当前打印错误和机型规则显示；不会给 HMS 批量执行恢复。“确定”始终只关闭本地提示，不发送 `clean_print_error`，也不恢复或完成打印。关闭弹窗不表示打印机故障已清除。
- 执行按钮前重新检查设备、在线状态、代码及状态版本；切换设备清空旧故障状态，避免操作到新设备。

### 显示时机与自动关闭

| 类别 | 自动弹出规则 | 关闭方式 |
| --- | --- | --- |
| 命令验证限制：HMS `0500-0500-0001-0007` / 打印错误 `84033543` | 每次开机或切换设备后，首次收到时最多自动弹一次；两种来源共用去重状态。空列表、错误清零、重复上报和 MQTT 重连不会重置这项记录 | 4 秒非模态提示条，也可点击收起；仍保留设备上报状态 |
| 已知普通信息：HMS 等级 3 / 打印错误低 16 位为 `Cxxx` | 新出现时显示；相同持续状态不重复弹 | 不带重试/完成动作时，单条 2 秒、多条 3 秒非模态提示条，也可点击收起 |
| HMS 错误、警告，打印停止/暂停错误，带重试/完成动作的提示 | 新故障出现时显示；多个故障共用列表 | 故障仍存在时需手动确认；打印机上报全部恢复时自动撤下 |
| 未知等级的 HMS／打印错误、被截断的故障列表 | 保守地作为需要确认的提醒 | 不计时关闭 |
| 用户主动操作收到的命令拒绝 | 作为该次操作结果显示，区别于设备自动上报的 HMS | 已知权限拒绝显示 4 秒警告提示条，其余失败手动确认；不自动重发 |

厂商对 HMS `0500-0500-0001-0007` 的说明是 MQTT 命令校验失败，并建议更新 Studio/Suite（含网络插件）或 Handy 后重试。界面中的“部分功能仅支持局域网模式，且开启开发者。”说明 xTouch 对此类受限控制采用的连接条件，不替代厂商故障说明，也不保证开启打印机开关后 Cloud 控制即可恢复；应使用相应的 LAN 设备连接。

HMS 的等级读取 `code` 的高 16 位，即完整 HMS 的第三组，不读取 `attr` 的部件字段。打印错误单独按低 16 位的首个十六进制数字分类。权限限制提示是明确的例外；其余未知代码不猜测安全等级。

计时只控制本地提示条，不清除故障状态。新故障、切换设备、手动关闭和状态恢复都会撤销旧计时器，防止旧计时器关闭新故障。重试/完成仍须匹配当前设备、在线状态、当前错误码和状态版本。

权限提示确认后，即使打印机间歇清除又重新上报，也不会在同一次设备会话反复单独弹出；若有其它新故障，合并列表仍可显示当前权限状态。用户再次主动发送被拒绝的控制命令，仍显示那次操作失败，避免误以为操作成功。

查看含义使用[故障码查询](https://tbc0309.github.io/xtouch-CN/errors.html)或[代码文档](ERROR-CODES.md)，固件不内置完整故障说明。

## 网页提示

管理页提示显示在“保存并重启”左侧；登录与配网页的提示显示在卡片下方居中。

| 原因 | 提示原则 |
| --- | --- |
| 未登录、会话失效 | 要求重新登录管理后台，不显示拓竹账号错误 |
| Cloudflare 拦截 | 显示 HTTP 状态，建议从官方登录取得 Token 后导入；不将账号判为密码错误 |
| 密码／验证码失败、Token 失效 | 使用对应认证结果，不和网络超时共用“登录失败” |
| 网络超时、服务器错误 | 保留网络／HTTP 类别，不清除之前保存的有效账号资料 |
| 配置校验失败 | 指明当前字段或原因；复用既有校验文案 |
| 已修改、待重启 | 统一待保存状态和“保存并重启”按钮，不为每项设置另造重启提醒 |
| 固件升级、导入备份、重置 | 独立结果及确认，不与普通保存成功混用 |

字典来源：基础界面 `src/ui/i18n/*.h`、扩展界面 `resources/ui-locales.json`、网页 `resources/portal-locales.json`。新增提示前先查同类原因和动作；只有信息或安全后果不同才新增条目。

## 刷写、升级与恢复

### 发布文件

| 主板 | 升级用应用镜像 | USB 安装用完整镜像 |
|---|---|---|
| ESP32-2432S028R | `xtouch-2.8.bin` | `xtouch-2.8-full.bin` |
| ESP32-S3-Touch-LCD-2.8 V2 | `esp32-s3-touch-lcd-2.8-v2.bin` | `esp32-s3-touch-lcd-2.8-v2-full.bin` |
| ESP32-P4-WIFI6-Touch-LCD-4.3 | `esp32-p4-wifi6-touch-lcd-4.3.bin` | `esp32-p4-wifi6-touch-lcd-4.3-full.bin` |

三板镜像不能混刷。应用镜像用于后台、OTA 和 SD 更新。各主板的 `ota.json` 为自动更新清单，用户无需编辑。

不要把完整 USB 镜像用于 OTA 或当作 SD 卡的 `firmware.bin`。手动将完整镜像写入 `0x0` 会覆盖 NVS；即使 SPIFFS 文件保留，设备凭据密钥也会丢失，已保存的加密凭据可能失效。保留设置请使用网页安装并取消勾选擦除。

### 网页在线刷写

电脑使用 Chrome 或 Edge 打开 **[在线刷写](https://tbc0309.github.io/xTouch-CN/)**。网页会记住上次选择的主板。数据线连接所选主板，加载刷写工具，选择对应串口并按提示安装。保留内部配置和校准时不要勾选 **Erase device**。CYD 全新安装后完成触摸校准；S3/P4 无需校准。随后扫码配网，从网页后台添加设备，无需 SD 卡。

S3/P4 无法自动进入下载模式时，确认已开机，按住 BOOT、点按 RESET，再松开 BOOT，重新连接串口安装。

网页会校验芯片、Flash 容量及每段写入数据的 MD5。默认安装避开 NVS 和 SPIFFS 用户数据区；勾选 **Erase device** 则先整片擦除再安装。SD 卡备份不会删除，启动时可能重新导入；需要全新配置时，先移除 SD 卡。擦除后从备份恢复的加密凭据可能需要重新输入。

也可使用页尾的[配置文件生成器（备用）](https://tbc0309.github.io/xTouch-CN/config.html)填写 Wi-Fi、局域网设备、已有 Access Token、时区和 NTP 服务器。下载 JSON 后从设备后台导入，或将 TF 卡配置包解压到卡根目录。文件在浏览器本地生成，包含明文凭据，请妥善保管；Token 和设备连接仍需在设备后台验证。

### 在线 OTA

设置页开启 OTA 后，下次开机连接 Wi-Fi，读取本项目主分支的[对应主板 OTA 清单](DEVELOPMENT.md#release)。只安装版本号更高的固件，同版本不会重复更新。

设备通过 HTTPS 下载对应 GitHub Release 的应用镜像，验证证书、完整长度与 MD5，有 SD 卡时先写入 SD 临时文件，验证通过后重启并写入备用程序分区；无 SD 卡时直接流式写入备用程序分区，完整校验后再切换启动。内部的 Wi-Fi、打印机、语言和触摸校准配置保留。

有卡更新时需为对应主板的应用镜像及临时文件留足 SD 空间；无卡更新不需要这部分空间。两者均需可访问 GitHub、其下载 CDN 和 NTP 的网络。更新期间保持供电，不要拔卡。时钟同步或网络失败会跳过更新继续启动；镜像下载最多尝试两次，不会无限重试。MD5 用于传输完整性，下载来源由 HTTPS 校验。

OTA 更新来源为 `tbc0309/xTouch-CN`。使用其他更新地址的固件，需先通过在线刷写或 SD 卡安装 CN 固件。

设置页的版本栏连续点击三次（相邻点击间隔不超过 0.8 秒）可手动检查并安装更高版本，无需开启开机 OTA 开关。开机或手动的更新清单检查最多 15 秒；该时限仅包括校时、DNS、TLS 和清单接收，不限制 Wi-Fi 配网、打印机连接或确认新版后的固件下载。网络失败返回设置页后会恢复打印机连接。

### SD 更新与恢复

初始化后的配置及备份规则见 [内部配置与 SD 同步](MAINTENANCE.md#storage)。

关闭设备，把对应主板的应用镜像复制到 SD 卡根目录并重命名为 `firmware.bin`，再开机。手动更新前移除 `/xtouch/ota.json` 及残留的 `.part` 文件，避免旧清单与手动固件不匹配。设备完成后自动删除更新文件。

没有清单的手动 SD 更新由 ESP32 更新模块检查镜像格式与分区大小；在线 OTA 还会按清单核验 MD5 和长度。无法启动时，使用网页在线刷写重新安装。SD 配置文件含设备访问凭据，请勿上传仓库或公开分享。

## 配网与账号管理

网页后台由各主板共用，按固件编译能力显示设置。CYD、S3 V2 与 P4 固件使用各自升级镜像，不能混刷。

### 初始化与设备管理

1. 无 Wi-Fi 配置时，扫描屏幕热点二维码，打开 `http://192.168.4.1/`。搜索后从“附近的 Wi-Fi”列表选择网络，也可手动填写名称。
2. 连接家庭 Wi-Fi 后访问设备地址，或在屏幕设置里打开“网页管理”扫码。点击二维码下方的“返回设置”返回。
3. 初始管理密码为 `12345678`，首次登录必须修改。管理账号固定为管理员；新登录替换旧会话。
4. “添加局域网设备”填写型号、LAN 地址、访问码和序列号后，点击 **验证并保存设备**。成功后自动保存并锁定输入框；双击修改连接参数后需重新验证，修改名称会自动保存。云端设备从对应账号的关联列表勾选加入。
5. 有效配置自动保存并生效，无需重启。编辑和排序不会切换屏幕当前设备。

连接参数、账号区域或凭据修改后，需重新验证成功才会保存；名称和备注仍自动保存。

屏幕和后台管理支持简体中文、繁体中文、英语、法语、德语、俄语、日语和韩语。屏幕语言与后台语言分别保存在设备配置的 `language` 和 `portalLanguage` 中，均默认英文；修改其中一个不会改变另一个。后台登录页和管理页共用后台语言，不使用浏览器自动语言或本地语言记忆。登录前临时切换的语言在登录成功后保存。首次 Wi-Fi 配网所选语言同时初始化两者，之后可分别更改。

公开刷机网站、配置生成器和故障码查询默认英文，可手动切换中英文；链接中的语言参数用于页面间跳转，不写入设备配置。

### 蓝牙配网（可选模块）

启用蓝牙配网模块的 S3／P4 固件，首次未配置网络时可选择 Wi-Fi 或 Bluetooth。选择 Bluetooth 后，在官方 **ESP BLE Provisioning** App 内扫描屏幕二维码，选择 2.4 GHz Wi-Fi 并输入密码；手动连接时设备名前缀为 `PROV_`，配网校验码为 `abcd1234`。配网成功或等待三分钟后蓝牙服务自动关闭。已配置设备可从屏幕设置页底部重新进入 Bluetooth 配网，原有打印机和账号配置保留。未编入模块的固件沿用 Wi-Fi 热点配网。

首次开机的配网选择页默认英文。首次通过蓝牙配网时，两种语言均初始化为英文；从设置页进入配网时，二维码界面跟随当前屏幕语言，原有语言配置保留。

### 拓竹账号

选择账号所属区域，粘贴 **Access Token** 并验证，即可读取关联打印机。获取方法见[获取与导入 Token](#token)。

验证成功后折叠账号信息，关联设备列表独立显示，可勾选加入或取消。已保存且有效的账号在打开账号管理时自动获取设备；临时网络失败不会直接判为账号失效。清除本地登录不等于撤销拓竹服务器上的 Token。

开机后依次检查账号与设备归属，之后每六小时复查；MQTT 认证拒绝也会触发复查。Token 过期或被拒绝时，重新从官网获取并在原账号卡片更新。

局域网设备使用青蓝色标识，Token 账号使用紫色标识。失效设备在屏幕上被选择时显示对应账号的管理二维码，浏览器打开后定位该账号。

### xTouch 设置、待机与声音

触摸音、警告音和自动深睡默认关闭。三板均支持提示音；音量在屏幕和后台均可调节，范围 0–100%，默认 20%。

联网待机关闭屏幕并降低功耗，保留 MQTT 和打印唤醒。可选深睡仅在打印机已知空闲、在线且无故障、维护或传输任务时进入；深睡期间网页和 MQTT 断开，不能即时接收打印唤醒。深睡唤醒会重新经过开机流程，不会清除配置。三板均支持触摸深睡唤醒，也可按复位键重新启动。

状态灯选项仅对可由软件控制的灯显示，RGB 状态灯默认开启。S3/P4 的电源、充电指示灯由硬件接线控制。

### 维护与重置

维护页支持下载配置、修改管理密码、上传应用固件和重置。上传同一主板的应用镜像，不使用 `-full.bin` 完整镜像；文件名见[发布与打包](DEVELOPMENT.md#release)。校验镜像芯片、大小与分区边界，成功后重启。

设置页版本号：连续三击检查 OTA；连续八击显示重置确认。确认重置后清除内部配置与管理密码、更新密码密钥，再从 SD 导入配置。无卡时重新初始化。开机 OTA 由设置开关控制，更新清单检查最长 15 秒。

[凭据与备份安全](MAINTENANCE.md#security) · [云端命令授权](PRINTERS.md#authorization)

### 自动深睡

后台“xTouch 设置 → 深度睡眠”可开启空闲自动深睡，并设置联网待机后的等待时间，默认 60 分钟。自动深睡默认关闭；深睡后不会定时启动，只能触摸唤醒或按复位键启动。普通联网待机与打印唤醒不受影响。

## 获取与导入 Token

Access Token 用于连接拓竹账号，与打印机的局域网访问码不同。请在电脑浏览器操作。

### 获取 Token

| 官网 | 地址 |
| --- | --- |
| 中国区官网（中文） | [bambulab.cn](https://bambulab.cn/) |
| 国际官网（英文） | [bambulab.com](https://bambulab.com/) |

1. 根据账号所属区域打开上方对应官网，完成登录。
2. 按 **F12** 打开开发者工具，选择 **Application（应用）**。找不到时点击工具栏的 `»`。
3. 左侧展开 **Storage → Cookies**，选择当前拓竹网站域名。
4. 搜索名为 **token** 的 Cookie，复制它的 **Value（值）**，不要复制整行或 Cookie 名称。

如果没有找到，确认官网登录成功后刷新页面，再检查相应域名。不要使用第三方网页收集 Token，也不需要在控制台粘贴脚本。

### 导入 xTouch-CN

1. 打开设备网页管理，进入 **拓竹账号 → 添加拓竹账号**。
2. 选择与官网账号一致的区域。
3. 粘贴 Token，点击 **验证并获取设备**。验证成功后会显示关联设备。
4. 勾选要添加的设备，有效配置会自动保存并生效。

已存在的账号可以展开原卡片更新 Token，无需重复添加。Token 过期或失效时，重新登录官网并重复以上步骤。

Token 相当于账号凭据，不要发到聊天、截图或公开仓库。配置备份也包含 Token，应妥善保管。Token 登录成功不代表所有控制命令均被打印机允许，详见 [云端控制说明](PRINTERS.md#authorization)。

获取步骤参考 [BambuHelper Token 教程](https://bambuhelper.stolaris.dev/cloud-token.html)，官网布局与登录策略可能变化。

表内共 19 个型号标识、23 个产品 ID；同一商品的不同版本可能使用不同标识。青萍蓝牙闹钟（CGD1）、青萍蓝牙小钟（CGC1）、秒秒测时钟温湿度计（MHO-C303）是带温湿度传感器的时钟产品。支持的是温湿度广播读取，不包含时钟、闹钟或其它附加功能控制。

支持表中产品 ID 的 MiBeacon v2/v3 明文广播、v4/v5 AES-CCM 加密广播，以及 0x1004/0x1006/0x100D 和 0x4801/0x4802/0x4808 温湿度对象。明文广播可只填写 MAC；加密广播必须有正确 BLE Key。不支持 v2/v3 旧加密格式、未知产品 ID、其它服务 UUID 或全部 MiBeacon 设备。不包含改刷固件的 ATC、PVVX、BTHome 格式。相同商品名的其它硬件版本或广播格式不保证兼容。温度显示一位小数，所有型号的湿度统一舍去小数部分，以整数百分比显示。数值由传感器广播更新；读数不变时可能不立即重报。首页可选关闭显示、交替显示或仅温湿度，默认交替显示；通过滑块设置交替间隔（1～30 秒），默认 5 秒。`~` 表示较旧读数。

### 获取 MAC 和 BLE Key

使用 [Xiaomi Cloud Tokens Extractor](https://github.com/PiotrMachowski/Xiaomi-cloud-tokens-extractor)：

1. 在手机米家 App 中添加温湿度计，通过蓝牙完成设备绑定。
2. Windows 下载项目 Releases 中的程序，或按项目说明安装依赖并运行 Python 版本。
3. 登录绑定该温湿度计的小米账号，选择对应服务器地区，例如中国大陆（`cn`）。
4. 在设备列表中找到该温湿度计的 `MAC` 和 `BLE KEY`，填入后台温湿度计配置。明文型号没有 BLE Key 时可只填 MAC。

下面仅为随机虚构示例，除名称和型号外均不是实际设备资料：

```yaml
NAME:     领普温湿度传感器
   ID:       blt.3.ee9d0ffd6159ce
   BLE KEY:  48449a24fb4394668c1b6a1d2cd5cfa3
   MAC:      02:86:B2:90:CE:4B
   IP:       192.0.2.48
   TOKEN:    67c7a9af1dd424a539997a4814043e03
   MODEL:    linp.sensor_ht.ks2bb
```

本功能只使用 `MAC` 和 `BLE KEY`，不需要 `ID`、`IP` 或云端 `TOKEN`。选择“加密并绑定”后，密钥绑定当前控制屏；在其它控制屏使用或重置设备密钥后需重新输入。

协议与型号参考：[Linp KS2](https://github.com/Tinnci/linpk2)、[Xiaomi BLE](https://github.com/Bluetooth-Devices/xiaomi-ble)、[ESPHome Xiaomi BLE](https://esphome.io/components/sensor/xiaomi_ble/)。

### 米家目录与兼容范围

米家 App 的“温湿度传感器”分类是商品目录，并不是 MiBeacon 协议兼容列表。本模块识别上表 19 个型号、23 个产品 ID；产品 ID 是广播中的型号编号，不是每台设备唯一的 `blt.…` ID。型号由广播自动识别，无需手工选择。

- 小米／Aqara 的 Zigbee 温湿度传感器不能由本模块直接接收。
- 标注 Wi-Fi 的 U-FAMILY U1、RSH Wi-Fi 等设备不属于本模块的 BLE 广播接入范围。

### 采集与显示时间

绑定后，控制屏被动监听广播，每 100 毫秒扫描周期监听 30 毫秒，不连接传感器，也不主动请求测量。上报周期和变化阈值由传感器决定，不能保证固定时间内收到新读数。

温度、湿度可能分开上报。只有绑定的传感器两项数据都收到后，首页才显示数值，并分别记录两项上报时间；密钥校验失败不会更新读数。重启或更换绑定会清空读数并等待新的广播；修改显示模式、交替间隔则保留已有读数。

首页每秒检查一次最新读数。“交替显示”按设定的 1～30 秒间隔轮换 AMS 与温湿度，默认 5 秒；没有 AMS 时直接显示温湿度。“仅温湿度”替代 AMS 展示；“关闭显示”只隐藏首页数值，仍继续接收。时间紧随摄像头图标，剩余宽度不足时隐藏。登录后台后，上报时间约每 5 秒刷新。

任一读数超过 10 分钟未收到更新时，保留上次读数并显示 `~`，表示收到的数据较旧，不代表已确认传感器故障。保存配置、刷新网页不会触发传感器重新上报；请保持传感器在附近，等待下一次测量广播。

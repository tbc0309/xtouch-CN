# 更新与维护

## 发布文件

- `xtouch-2.8-full.bin`：完整 USB 镜像，首次安装写入 `0x0`。
- `xtouch-2.8.bin`：应用镜像，USB 写入 `0x10000`，也用于 OTA 和 SD 更新。
- `ota.json`：自动更新清单，包含版本、应用下载链接、字节数和 MD5；用户无需编辑。

不要把完整 USB 镜像用于 OTA 或当作 SD 卡的 `firmware.bin`。

## 在线 OTA

设置页开启 OTA 后，下次开机连接 Wi-Fi，读取本项目主分支的 [ota.json](https://raw.githubusercontent.com/tbc0309/xtouch-CN/main/ota.json)。只安装版本号更高的固件，同版本不会重复更新。

设备通过 HTTPS 下载对应 GitHub Release 的应用镜像，验证证书、完整长度与 MD5，先写入 SD 临时文件，验证通过后重启并写入备用程序分区，再重启进入新版本。SD 上的 Wi-Fi、打印机、语言和触摸校准配置保留。

需要 SD 卡有至少 2MB 可用空间，以及可访问 GitHub、其下载 CDN 和 NTP 的网络。更新期间保持供电，不要拔卡。时钟同步或网络失败会跳过更新继续启动；镜像下载最多尝试两次，不会无限重试。MD5 用于传输完整性，下载来源由 HTTPS 校验。

自动更新只指向 `tbc0309/xtouch-CN`，不下载上游英文固件。旧版未修改更新地址的固件需要先通过 USB 或 SD 安装本版本。

## SD 更新与恢复

关闭设备，把 `xtouch-2.8.bin` 复制到 SD 卡根目录并重命名为 `firmware.bin`，再开机。手动更新前移除 `/xtouch/ota.json` 及残留的 `.part` 文件，避免旧清单与手动固件不匹配。设备完成后自动删除更新文件。

没有清单的手动 SD 更新由 ESP32 更新模块检查镜像格式与分区大小；在线 OTA 还会按清单核验 MD5 和长度。无法启动时，用 USB 在 `0x0` 重刷完整镜像。SD 配置文件含设备访问凭据，请勿上传仓库或公开分享。

# 更新与维护

简体中文 | [English](UPDATING.en.md) | [README](../README.md)

## 发布文件

- `xtouch-2.8-full.bin`：完整镜像，供网页在线刷写使用。
- `xtouch-2.8.bin`：应用镜像，用于 OTA 和 SD 更新。OTA 会在两个程序分区之间切换，网页在线刷写使用完整镜像。
- `ota.json`：自动更新清单，包含版本、应用下载链接、字节数和 MD5；用户无需编辑。

不要把完整 USB 镜像用于 OTA 或当作 SD 卡的 `firmware.bin`。完整镜像从 `0x0` 写入会重新设置启动分区，范围不包含内部 SPIFFS 配置区；刷写工具若选择整片擦除，仍会清空配置。

## 从上游原版卡刷到 CN

$\color{red}{\text{支持原版 xTouch 固件通过 SD 卡直接升级为本项目 xtouch-CN 固件。}}$

1. 下载本项目 `xtouch-2.8.bin`，改名 `firmware.bin`，放到 SD 根目录。不要放完整 USB 镜像，也不要放上游原版固件。
2. 保留原版 `xtouch.json` 和 `xtouch` 文件夹中的设置、校准；移除遗留的 `xtouch/ota.json`，避免旧摘要与新镜像不符。
3. 插卡启动，原版内置卡刷器会把 CN 应用写入备用分区。完成后自动重启。
4. CN 首次启动先备份原版配置为 `.bak`，再迁移为新版多设备格式并保存内部。完成联网后即可脱卡运行。

已使用本项目 OTA 地址的 CN 固件，开启 OTA 后重启即可检查更新。升级保留配置，相同版本不会重复安装。
## 网页在线刷写

电脑使用 Chrome 或 Edge 打开 **[配置生成与在线刷写](https://tbc0309.github.io/xtouch-CN/)**。数据线连接 CYD 主板，加载刷写工具，选择对应串口并按提示安装。保留内部配置和校准时不要勾选 **Erase device**。全新安装后准备 SD 配置并完成校准。

## 在线 OTA

设置页开启 OTA 后，下次开机连接 Wi-Fi，读取本项目主分支的 [ota.json](https://raw.githubusercontent.com/tbc0309/xtouch-CN/main/ota.json)。只安装版本号更高的固件，同版本不会重复更新。

设备通过 HTTPS 下载对应 GitHub Release 的应用镜像，验证证书、完整长度与 MD5，有 SD 卡时先写入 SD 临时文件，验证通过后重启并写入备用程序分区；无 SD 卡时直接流式写入备用程序分区，完整校验后再切换启动。内部的 Wi-Fi、打印机、语言和触摸校准配置保留。

有卡更新时需要至少 2MB SD 可用空间；无卡更新不需要这部分空间。两者均需可访问 GitHub、其下载 CDN 和 NTP 的网络。更新期间保持供电，不要拔卡。时钟同步或网络失败会跳过更新继续启动；镜像下载最多尝试两次，不会无限重试。MD5 用于传输完整性，下载来源由 HTTPS 校验。

OTA 更新来源为 `tbc0309/xtouch-CN`。使用其他更新地址的固件，需先通过在线刷写或 SD 卡安装 CN 固件。

设置页的版本栏连续点击三次（相邻点击间隔不超过 0.8 秒）可手动检查并安装更高版本，无需开启开机 OTA 开关。开机或手动的更新清单检查最多 15 秒；该时限仅包括校时、DNS、TLS 和清单接收，不限制 Wi-Fi 配网、打印机连接或确认新版后的固件下载。网络失败返回设置页后会恢复打印机连接。

## SD 更新与恢复

初始化后的配置及备份规则见 [内部配置与 SD 同步](STORAGE.md)。

关闭设备，把 `xtouch-2.8.bin` 复制到 SD 卡根目录并重命名为 `firmware.bin`，再开机。手动更新前移除 `/xtouch/ota.json` 及残留的 `.part` 文件，避免旧清单与手动固件不匹配。设备完成后自动删除更新文件。

没有清单的手动 SD 更新由 ESP32 更新模块检查镜像格式与分区大小；在线 OTA 还会按清单核验 MD5 和长度。无法启动时，使用网页在线刷写重新安装。SD 配置文件含设备访问凭据，请勿上传仓库或公开分享。
